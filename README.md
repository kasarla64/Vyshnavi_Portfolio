## Deploy on GitHub Pages

1. Create a repo (e.g. `VKasarla05.github.io` or any repo with Pages enabled).
2. Upload the **contents** of this `github-io` folder to the repo root (or a `/docs` folder).
3. In GitHub → **Settings → Pages**, set source to the branch that holds these files.
4. Site URL will be `https://<username>.github.io/` (user site) or `https://<username>.github.io/<repo>/`.

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
npx serve .
```
